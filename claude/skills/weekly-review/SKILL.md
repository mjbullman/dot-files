# weekly-review — Tiago Forte's five-step Weekly Review

Guide the user through Forte's **Weekly Review**: five steps, in order, aimed at ~30 minutes flat. It's "preventative maintenance for the mind," not a full audit.

This skill is **hands-off**: it never reads mail, lists folders, queries Things/Obsidian, opens any app, or writes anything. Each step is just the **direction** for what to do — the user switches to the app themselves and does the one-touch work. Don't open apps: launching one steals focus and the user loses the directions.

Run the steps **strictly in order, one at a time**: give the direction → wait. "Next" advances; "back" returns to the previous step. Keep the tone brisk — this is a fast reset, not a deep review.

**Presentation:** each step is a tight bullet list of directions, one per line — never prose paragraphs. Fast to scan is the whole point.

The method is **one-touch**: touch each item once, deciding what it needs rather than doing it. The order isn't arbitrary — email is first because it's the biggest source of new items, and each step routes its leftovers into a later step's inbox (an email becomes a calendar entry, a download, a note, or a task). By the Tasks step the downstream inboxes have already been fed.

## Step 1 — Email

- Triage each inbox to zero (all Outlook accounts)
- One-touch every message — decide, don't do
- Meeting/invite → leave for the calendar step · action → Things task · reference → vault note · else → archive/delete

## Step 2 — Calendar

- Scan **two weeks back** — follow-ups you owe (thank-yous, decisions, loose ends)
- Scan **four weeks forward** — prep needed, approaching deadlines, conflicts
- Capture any open loop as a Things task (the Tasks step sweeps them up)

## Step 3 — Desktop / Downloads

- One-touch each file — delete, file into PARA, capture into the vault, or task it
- Keep anything that's real intellectual effort; bin the clutter

## Step 4 — Notes

- Empty the `00 - Inbox/` — file each note into a Project/Area/Resource, or delete it
- Daily notes: promote unchecked follow-ups to Things, then archive the daily
- Clippings (`type/clipping`): distil to a line in your own words and keep, or delete

## Step 5 — Tasks

- Clear the Things Inbox — assign each item a project/area, or delete it
- For each kept task: define the next action, set a project/area, add High/Medium priority only
- Pick next week's **top three priorities** and put them on Today/This Week

## Step 6 — Archive

The one addition to Forte's five steps, per the vault's archive cadence (vault `CLAUDE.md`):

- Walk `10 - Projects/` — anything **completed** (work done, no open Things next action)? Move the whole folder (assets included) to `40 - Archive/` and complete the mirrored Things project
- Anything **stalled** (no activity, no next action across ~4 reviews)? Archive the folder or demote the Things project to Someday
- Nothing to archive is a clean, normal result

## Out of scope

- Any write, query, or app launch — mail, folders, Things, Obsidian, YouTrack, GitHub. The skill only gives directions; the user does everything else.
- No review note is produced (Forte's review writes nothing).
- Deep audits — GitHub PR sweeps, YouTrack carry-over review, Projects/Areas mirror checks. Those are a separate, heavier review, not the weekly reset.
